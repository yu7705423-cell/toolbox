做一个你自己的前端

这个页面自带的管理界面是最简单的通用版。如果你想要更个性化的样式或功能，复制下面的 Prompt 交给 AI（比如 Claude、ChatGPT）帮你改造，改好之后把生成的完整 HTML 粘贴回下面的框里，点击"接入我的图床"，工具会把你已经保存的图床配置自动接入进去。

1. 复制这份 Prompt 去改造前端

Prompt 里已经写清楚了图床的接口约定（上传/删除函数签名），AI 只需要照着接口写界面，不会破坏对接。

2. 把 AI 生成的 HTML 粘贴回来

工具会把你在"搭建图床"里保存的配置和图片记录，注入进这份新 HTML 的 localStorage 初始值里，下载后打开即为已连接状态。
