# 工具箱

自己写的那些网页工具，现在住在同一个仓库里、长同一个样、互相之间走得通。

```
https://yu7705423-cell.github.io/toolbox/
```

打开后**添加到主屏幕**，整箱工具就是一个 app。

## 里面有什么

| | 栏 | 目录 | 干什么 |
|---|---|---|---|
| 番外生成器 | DIY | `fanwai/` | 选几个梗，产出一段 Prompt |
| 世界书生成器 | DIY | `worldbook/` | 写世界书，带审查和评分 |
| 图床工具箱 | DIY | `imgtest/` | 自建图床的上传和管理 |
| 喵喵书阁 | 收纳 | `read/` | 存番外和长篇，能朗读 |
| Chat Archive | 收纳 | `archive/` | JSON 备份当聊天记录翻 |
| 世界书库 | 收纳 | `worldbook/library.html` | 世界书的存放、导入导出和备份 |

**DIY** 是拿来做东西的（都要配 API 或密钥），**收纳** 是拿来存东西的
（打开就是你的东西，什么都不用配）。合集页按右上角 **?** 能看到每个工具的
「什么时候用」和「东西存哪」。

> 这些工具原来各有一个仓库（`fanwai`、`imgtest`、`read`、`memory`）。
> 代码已经搬到这里，**以后只改这里**，那几个仓库是旧版。

## 让它们像一家人的三个文件

| 文件 | 管什么 |
|---|---|
| `theme.css` | 全站的颜色、圆角、间距、字体。纯黑白，白天夜里各一套 |
| `skin/<工具>.css` | 把这个工具自己那套变量的值指到 `--tb-*` 上。**不改它一条 CSS 规则** |
| `shell.js` | 唯一的工具名录 + 日夜同步 + 「切换工具」面板 |

一个工具接进来只要三行：

```html
<!-- 放在它自己的 <style> 之后，才压得住它原来的颜色 -->
<link rel="stylesheet" href="../theme.css">
<link rel="stylesheet" href="../skin/你的工具.css">
<!-- 放在 </body> 前 -->
<script src="../shell.js" data-tool="你的工具id"></script>
```

再在它自己的顶栏里塞一颗按钮（位置随它自己的布局，不用统一）：

```html
<button class="tb-btn" data-tb-switch type="button" title="切换工具">⇄</button>
```

没塞也行 —— 外壳会在右下角自己生一个，保证任何工具都走得回去。

### 加一个新工具

1. 新建目录，把单文件 HTML 放进去（`你的工具/index.html`）。
2. 加上面那三行 + 一颗 ⇄ 按钮。
3. 写一份 `skin/你的工具.css`，把它的变量名映射到 `--tb-*`。
4. 在 `shell.js` 的 `TOOLS` 里加一条。

第 4 步做完，合集页的卡片和每个工具里的切换面板会**同时**多出来 ——
名录只有那一份。

## 日夜是谁说了算

全站一个设置，存在 `localStorage` 的 `toolbox.v1` 里。

工具自己也记着一份主题（书阁、图床都有自己的主题按钮），它们启动时会把
`data-theme` 改成自己那份。所以 `shell.js` 会在页面 load 之后再压一次，
之后才开始听 —— 这时候 `data-theme` 再变，就是人真的点了工具自己的主题
按钮，那就反过来记进全站设置，让其他工具跟着变。

## 数据

每个工具的数据都在**这台设备的浏览器里**，各存各的，互不干扰。
世界书生成器和世界书库是唯一共用一个库的一对（同源，同一个 IndexedDB）。

工具之间还不能互相传东西（比如把图床的图直接发给书阁）—— 同源这个前提
已经有了，要做的时候再做。

## 文件

```
index.html      合集页
theme.css       全站的颜色/圆角/间距/字体 + 外壳零件的样式
shell.js        工具名录 + 日夜同步 + 切换面板
skin/           每个工具的换肤表
sw.js           离线外壳缓存。改了 index.html / theme.css / shell.js 要把 VERSION 加一
manifest.json   加到主屏用
icon-*.png      图标，黑底 + 四个白格子
fanwai/ imgtest/ read/ archive/ worldbook/    六个工具
```
