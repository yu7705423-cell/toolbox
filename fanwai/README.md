# 番外 / 小剧场 Prompt 生成器

一个纯前端、移动端优先的单文件 Web App。

**它不是故事生成器。** 它是一个 **Prompt 编译器 / 嗑点翻译器**：你写下脑洞、随手选几个梗，
它负责理解、整理、细化，最后产出一段可以直接复制到 ChatGPT / Gemini / Claude / SillyTavern 等模型里执行的 Prompt，
由那边结合当前角色与聊天上下文去写真正的番外正文。

你选的是**感觉**，不是写作指令。

## 打开方式

`index.html` 是整个应用，双击用浏览器打开即可（也可以放到任意静态服务器 / GitHub Pages）。
没有构建步骤、没有依赖、没有后端。

## 核心机制：语义翻译层

抽象标签不会被原样丢给模型，因为那些词很容易让模型直接套刻板人物模板，导致 OOC。
工具内置一套「用户标签 → AI 行为语言」的映射词典，并且完全可编辑：

| 你选的 | 写进 Prompt 的 |
|---|---|
| 占有欲 | 对对方存在明显的特殊关注，在对方与其他人互动时出现自然的情绪变化，通过行为、语气和细节表现，而不是通过控制对方体现 |
| 下克上 | 让关系中的主动权逐渐发生变化，使原本处于优势的一方逐渐受到另一方影响 |
| 暗戳戳吃醋 | 情绪只通过细微动作、语气停顿、话题转移或不合常理的小举动流露，角色不会承认 |

词典支持增删改、恢复默认、导出成词典包分享给别人、导入别人做好的词典包。

## 功能

- **脑洞优先**：一句话也能生成 Prompt；用户自由脑洞的优先级高于所有预设标签。
- **AI 编主线**（需要 API）：只选了标签、脑洞栏空着的时候，可以让 AI 按这些梗编一条**具体的主线**——
  谁、什么处境、发生了什么、转折和落点，一段连贯的话，而不是把标签罗列出来。
  已经写了脑洞的话，按钮变成「补完这条主线」，在保留你原意的前提下补细节。编出来可以当场改、换一条、追加或替换。
- **标签体系**：情感张力 / 关系张力 / 情绪嗑点 / 剧情元素 / AU / 小剧场，支持多选、自定义、重命名、排序、删除、恢复默认，并可自建分类。
  每个分类在选标签的地方就能直接「+ 添加」，加完自动选中；人物性格、场景、影视类型、氛围、风格、钩子、篇幅这些组同样能加，
  加过一次就一直在选项里（在「标签池」页可以回看和删除）。
- **AI 批量生成标签**（需要 API）：按分类和你给的方向一次生成一批标签，**同时生成每个标签的行为语言翻译**，
  勾选后一并进标签池和语义词典；重复的会标出来并默认不勾。
- **AI 指令可编辑**：本工具调用模型时发过去的系统指令（AI 整理 / 编主线 / 批量生成标签 / 四档编译强度）全部可以自己改，
  可单条或全部恢复默认，也能导入导出。
- **随机抽取**：指定数量、指定「想要 / 不想要」、整体重抽或只重抽某一个；自定义标签同步进入抽取池。
- **标签冲突检测 / 关联推荐**：方向相反的标签会在编译前提示，由你决定，工具不替你取舍。
- **人物设定**：CHAR / USER 字段完全独立且对等，全部选填，绝不默认 CHAR × USER，不根据性别 / 职业 / 身份推导性格能力；支持任意数量的其他角色与「谁对谁是什么」的关系图谱。
- **关系动态**：权力差 / 暧昧 / 吃醋 / 情绪拉扯 / 反差 / 主动权 / 身份差 / 关系变化等可调强度滑块，名称与两端文字可自定义。
- **世界观 / 场景 / 参考作品**：文学与影视参考只取气质与叙事方式，明确要求不复刻原作。
- **氛围 / 叙事 / 视觉 / 结局 / 加料 / 拒绝清单**：拒绝清单会单独列在最终 Prompt 末尾。
- **篇幅控制**：目标字数、严格篇幅模式、长篇分段模式、输出总字数；配套独立的**篇幅检测**工具（统计实际字数、算出还差多少、一键生成续写指令）。
- **我的 Prompt**：自己的前置指令作为一等配置独立存在，可新建 / 编辑 / 复制 / 启停 / 排序 / 导入导出。
- **Prompt 模板**：你自己那套**固定的开头约束 ＋ 中间自动填本次番外 ＋ 固定的结尾约束**。
  开头结尾每篇都一样、中间每篇都不同，可以存好几套换着用；不想要工具自带的那几段约束，到「模块顺序」里关掉即可。
  另有高级模式，用 `{{USER_IDEA}}` `{{CHARACTERS}}` `{{MODULES}}` 等变量自己排布整篇。
- **模块顺序**：12 个默认模块可排序、开关、加自定义模块，决定模板中间那段的内容与顺序。默认顺序把脑洞放在开场之后、约束类放到后面，跟自己手写要求时的语序一致。
- **输出形态**：默认「自然段落」——像自己手写要求那样，开场一句、接着一整段讲清楚这一篇具体要什么、最后一句篇幅要求，
  没有 `【】` 分区、没有逐条罗列；另有「分区块」形态，把人物、关系、叙事、篇幅分块列出来。
- **编译强度**：原汁原味 / 轻度润色 / 深度细化 / 大胆扩展。
- **三段预览 + 版本管理**：AI 理解 / 番外方向 / 最终 Prompt；每次重新编译生成 v1、v2、v3…，旧版本不会被覆盖。
- **番外库**：我的番外 / 他人分享两个分区，文件夹、搜索、筛选、收藏、单条删除、批量移动删除导出、单条 / 批量 / TXT / 全库导入导出。他人分享的来源信息全部选填，缺失就留空，工具不会编造。
- **预设**：把一整套配置存下来复用（不预置任何示例，一开始是空的）；删除预设不影响已保存的番外。
- **分享码**：把某个预设或番外配置压成一段 `FW1:` 短码发给朋友直接导入。
- **口味画像**：把你常选的标签组合摆出来看看，纯展示，不做推荐、不影响生成。
- **API 设置**（可选）：OpenAI 兼容接口，多套配置、**一键拉取模型列表**（全部列在下拉框里选，记住上次拉到的结果）、连接测试。**不配置也能完整使用**，本地编译已经能产出完整 Prompt。

## 联动：送到喵喵书阁（可选，默认关闭）

**这是一个可选开关，默认关着，关着的时候界面上不会出现任何跟书阁有关的东西。**
不用书阁的话，这个工具本身就是完整的：编译、复制、粘贴给你的模型，跟联动没有任何关系。
要用就到「数据备份 → 可选联动」打开它。

打开之后：生成器管「要什么」，[喵喵书阁](https://github.com/yu7705423-cell/read) 管「得到了什么」，
接口是书阁的**指令（instruction）**：这边一条编译好的 Prompt = 那边的一个指令，
正文写好之后按书阁原本的流程建故事、选这个指令挂上去。

**两个应用放在同一个站点下时**（例如 GitHub Pages 的 `/fanwai/` 和 `/read/`），
点「送到喵喵书阁」就直接写进书阁的收件箱并跳过去，书阁打开就收，不用导文件；
书阁标签页本来就开着的话当场就收到了。入口有三处：编辑器的预览区下方、番外详情页、番外库的批量操作。

- 送过去的内容：标题、最终 Prompt、标签，以及脑洞 / AI 理解 / 番外方向（写进指令的备注）。
- **同一条番外改完再送是更新**那条指令，不会在书阁里堆出一堆重复的。
- 书阁地址在「数据备份 → 可选联动」里配置，默认 `../read/`；那一页会直接告诉你现在是直通还是走文件。
- **不同源时**（各自本地打开、或换了域名）自动改成导出一个交接文件，
  到书阁的「设置 → 数据备份 → 导入」选它即可，书阁认识这种格式——**这不是出错，只是另一种走法**。

## 数据与隐私

- 全部数据存在浏览器本地 **IndexedDB**：`stories` `prompts` `promptTemplates` `presets` `apiConfigs` `folders` `settings` `lexicon` `tagpool`。
- 番外内容、Prompt、预设、API Key 都不会上传。
- 只有在你主动开启「AI 整理」时，浏览器才会直接请求你自己填写的接口。
- 导出配置与全库备份默认**不含 API Key**；导入只解析 JSON 数据，不会执行文件里的任何代码。
- 换设备或清理浏览器数据前，记得在「数据备份」里导出一份。

## 最终 Prompt 的硬性约束

生成的 Prompt 可以独立复制使用，不依赖本工具、不含内部变量、不输出「未指定」这类占位内容，空模块直接省略；
并且会明确要求目标模型：不要把番外写成主线、不要修改原剧情、不要擅自改变人物、不要强行 CHAR × USER、
不要套性别刻板印象、不要把标签逐项打卡、不要在正文前输出分析、不要用总结凑篇幅、不要虚报字数、
不要把没提供的信息写成固定事实。

## 技术

原生 HTML + CSS + JavaScript，无框架、无第三方库，单文件约 3900 行。
UI 图标全部为内联 SVG（不使用 Emoji）。移动端优先，同时适配桌面浏览器，支持系统深色模式。
所有编辑自动保存，刷新不丢数据。
